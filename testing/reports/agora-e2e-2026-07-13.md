## Blocking findings

1. **`open_registration` mismatch** — Agora codex requires invitation-only; realm entity has `open_registration=true`. Blocks A3.9 and undermines incumbent registration model.
2. **Organization seeding not applied** — `organizations_count=0`; no position invite codes; Organizations UI cannot be exercised. Blocks A4 and civil-servant onboarding.
3. **Stale `manifest_data` departments** — Realm reflects an older Agora package shape (5 legacy depts), not v0.6.0 civic scaffolding. Suggests codex init ran with an old package or init/seeding failed silently.
4. **Public dashboard anonymous load** — Logged-out `/extensions/public_dashboard` hangs on loading spinner; incumbent migration UI never appears.

## Cosmetic / test-infra findings

- Playwright spec needs fixes: wait for SPA hydration, don't click disabled wizard steps, don't require Test Mode banner on join page when `test_mode_ii_bypass=false`.
- `extension_sync_call` is an **update** (not query); use `extension_call` for read-only backend assertions.
- `dfx` panics on `ColorOutOfRange` unless `CI=true FORCE_COLOR=0` is set.
