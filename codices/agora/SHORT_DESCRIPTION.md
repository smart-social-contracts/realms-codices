# Agora

A migration codex for an existing public administration moving its entire IT to Realms GOS (a 1-to-1 migration). The population already exists, so onboarding is by registration code or bulk/programmatic import — no ZK passport. During the migration phases citizens pay nothing; their member dashboard simply shows their declaration and any potential future tax deadlines, while the public dashboard tracks the percentage of the population migrated and the departments coming online. Quarters and their zones are defined in advance. Once live, the realm runs direct-democracy governance, justice, procurement, welfare, and real-time double-entry accounting.
